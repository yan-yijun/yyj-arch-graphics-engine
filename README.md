# YYJ Architectural Graphics Engine

Minimal React + TypeScript + Vite starter for a 2D architectural graphics and layout engine.

## Local development

```bash
npm install
npm run dev
```

## Build check

```bash
npm run build
```

## Codex environment

After these files are committed to the repository's `main` branch, create/retry the Codex environment.

If Codex asks for a setup command, use:

```bash
npm install
```

This starter intentionally contains only a minimal SVG-ready shell. The Codex build task should implement the actual graphics engine on top of it.
